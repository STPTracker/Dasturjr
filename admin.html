Biometric data never leaves the student's device

VeriTap uses WebAuthn/passkeys backed by each phone's secure hardware. Only a cryptographic verification result and credential metadata are stored here — never a fingerprint image or template. This is a multi-factor anti-proxy system: NFC card + on-device biometric + registered-credential match, combined with duplicate-attempt blocking and full audit logging. No attendance system can be claimed mathematically impossible to bypass — this design is intended to make proxy attendance significantly harder and fully auditable.

One extra step for real logins

Adding someone here saves their name, email and role/permissions. To let them actually sign in, also add that same email in Firebase Console → Authentication → Users, then replace this record's ID with that user's UID (Firestore → admins collection) so the security rules recognize them. This two-step process exists because creating real login accounts requires elevated (Admin SDK) privileges this browser-only app intentionally never holds.
