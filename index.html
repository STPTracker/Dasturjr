Biometric data never leaves the student's device

VeriTap uses NFC card identity plus on-device camera face matching and software liveness. Face descriptors (not photos) and attendance results are stored — never raw verification video. This is a multi-factor anti-proxy system: NFC card + on-device biometric + registered-credential match, combined with duplicate-attempt blocking and full audit logging. No attendance system can be claimed mathematically impossible to bypass — this design is intended to make proxy attendance significantly harder and fully auditable.
